A check is not the same thing as the asset failing. The asset can materialize
successfully and still be marked invalid — that distinction *is* the feature.

```python
@asset_check(asset=daily_revenue, blocking=True)
def revenue_is_plausible() -> AssetCheckResult:
    ...
```
