**A1 — hint 2 of 2**

You do not need to write any HTTP code. `source.client_from_airflow_conn("supplyhub")`
returns a client; `client.get_delivery(business_date)` returns metadata;
`client.download(meta, delivery_file(meta.business_date))` writes the bytes.

Your job is the wiring, not the fetching.

If you are seeing an authentication error: you have **two** team secrets. The
join code got you your config. The SupplyHub token — it starts with `sh_` — is
what the connection needs.
