**A2 — hint 2 of 2**

Once you know the delivery is stale: **will asking again produce a different
answer?**

What would have to be true about SupplyHub for a retry to help — and is it true
here? Try it if you are not sure. Three retries against a deterministic endpoint
fetch the same file three times.

Whatever you decide, the `retries` setting on that task is now a deliberate
choice rather than an inherited default. Make it one.

(And: do not hardcode `"2026-03-03"` in your check. A4 runs a different date
through the same pipeline.)
