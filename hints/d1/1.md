```python
@asset(deps=[raw_delivery], description="...")
def clean_sales(context: AssetExecutionContext) -> MaterializeResult:
    ...
```

Not as a function parameter. These assets return `MaterializeResult` rather than
a value, so there is no stored output for Dagster to hand to a parameter — and
no IO manager configured to fetch one.

Then look at the lineage view and confirm the graph is actually connected.
