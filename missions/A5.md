## Where we are

Finance wants a summary report built from `daily_revenue`.

When should it run?

The obvious answer is "at 07:15, after the pipeline". Think about what that
assumes.

## Your task

Add a second DAG — a new file in `dags/` — scheduled on the asset your A4 task
publishes:

```python
schedule=[Asset(name="rootsmarkt_daily_revenue", uri="rootsmarkt://warehouse/daily_revenue")]
```

It should read the metadata from the asset event that triggered it and log the
revenue total it was triggered by. Look at `triggering_asset_events` in the task
context.

Declare the `Asset` again in the new file rather than importing it from the other
DAG. Assets are identified by name and URI, not by object identity — and
importing across DAG files re-executes the other module, which registers its DAG
twice and makes Airflow reject the duplicate.

## What success looks like

The consumer DAG **does not run** for the €0 delivery, because no asset event was
published for it. It runs automatically after a good one, with no schedule
interval anywhere in the file.
